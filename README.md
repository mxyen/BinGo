# BinGo ♻️
Turning waste into value through smart sorting, recycling and rewards.

## ¿Qué hace?
- **Clasificar residuos**: escribe el nombre del residuo o toma una foto y la IA (MobileNet + TensorFlow.js, en el navegador) te dice en qué contenedor va.
- **Puntos y recompensas**: gana puntos cada vez que reciclas, sube de nivel y canjéalos por recompensas.
- **Impacto**: estadísticas de residuos reciclados y CO₂ evitado (aprox.).

## Ejecutar
```bash
npm install
npm run dev
```
Abre http://localhost:5173

## Tecnologías
React + Vite + TypeScript · TensorFlow.js (MobileNet) · localStorage
